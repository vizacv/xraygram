# Бэклог фич

Ведёт продукт (`product/`), заводит оркестратор. Спецификации — `product/features/FEAT-NN.md`,
единое поведение и расхождения платформ — `product/parity.md`, дорожная карта — `product/roadmap.md`.
Статусы: `—` не начато · `🔨` в работе · `🧪` собрано, ждёт QA · `✅` проверено · `⚠️` с оговорками · `❌` сломано ·
`👤` ждёт владельца · `🚫` не делаем · `n/a` к платформе не относится.
Приоритет: **P1** — без этого нельзя давать людям · **P2** — важно, следующим кругом · **P3** — потом / по запросу.
«Выровнять» — платформа сделала, но не так, как в спеке; задачи `PAR-NN` в `product/parity.md`.

## Что изменилось при наведении порядка (продукт, 2026-11-18)

- FEAT-01: в фичу включены понятные тексты ошибок (BUG-08) и единый формат превью; на всех платформах — выровнять тексты.
- FEAT-02: добавлено правило «выключить прокси при XRAY-записях — только с подтверждением» (сейчас везде уходит напрямую молча).
- FEAT-03 Android: код экрана уже в патче, но APK с ним не собран и не зарегистрирован → 🔨.
- FEAT-04: найдено, что Android предлагает все версии звонков, включая `InstanceV2PumpImpl` (18/19) без прокси —
  звонок такой версии пойдёт напрямую (iOS это уже исключил). Предупреждение перед групповым звонком перенесено в FEAT-04
  (P1), сами групповые звонки через xray остаются FEAT-05 (P3).
- FEAT-09 поднят до P1 для Android; ред. 2 (ответ владельца на В4): пуши через свой проект FCM, фоновое соединение — запасной путь.
- Новые: FEAT-13 (подписка), FEAT-14 (автовыбор сервера), FEAT-15 (поделиться/QR), FEAT-16 (проверка ссылки),
  FEAT-17 (комплект для друга), FEAT-18 (Windows).
- FEAT-08 на macOS — 🚫: регистрация схемы `vless://` перехватит ссылки у других клиентов, буфера достаточно.
- Ответы владельца 2026-11-18: В1 → делиться можно (FEAT-15, спека), В2 → подтверждение при выключении прокси,
  В3 → RU/EN по языку системы, В4 → пуши FCM (FEAT-09 ред. 2), В5 → Windows потом.
