# Оркестрация

## Роли

- **Оркестратор** (главная тема, `~/xraygram`): общение с владельцем, поиск и проверка,
  постановка задач системным темам, приёмка результата, общие документы в `docs/`.
- **Системная тема**: одна платформа. Пишет только в свою папку (`macos/`, `android/`, ...)
  и в `upstream/<свой-клон>`. Ведёт свою базу знаний: `<система>/README.md` (статус, как собрать)
  + заметки рядом. Ничего не коммитит и не пушит, пока оркестратор не скажет.

## Правила

- Общий репозиторий один: `~/xraygram` (git). Коммиты и пуш делает оркестратор после проверки.
- Чужие папки не трогать. Если нужно изменить общее — написать оркестратору.
- Секреты (api_id/api_hash, ключи подписи) — только в GitHub Secrets, не в файлах.
- Язык общения и документов — русский.
