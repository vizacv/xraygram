# Тема «Рентген»

Выбрана владельцем 2026-11-19 из трёх направлений (макеты: https://claude.ai/artifact/PKELvHywueRLGEP7T8AK84 —
приватный холст владельца; направление «А · Рентген»). Это **тема по умолчанию** на всех платформах; обычные темы
Telegram остаются в настройках, их не трогаем. Раскладку экранов (список чатов, чат) не меняем — только цвета,
статус XRAY, заставку, вступление и иконки (решение 2026-11-19: полного редизайна нет).

Акцентное свечение (по желанию платформы, если дёшево): `box-shadow 0 0 24px rgba(62,242,200,.35)` у плавающей
кнопки и у значка статуса.

## Шрифты

Основной — системный (как у upstream). Моноширинный — для технических данных: имя сервера, пинг, значок статуса,
ссылка `vless://`, надпись `XRAYGRAM`. Лучше JetBrains Mono (OFL), если встраивание дёшево; иначе системный
моноширинный (SF Mono / Roboto Mono / Menlo).

## Значок статуса XRAY

Пилюля по центру под заголовком списка чатов: точка + `XRAY · <сервер> · <пинг> мс`, моноширинный 12, фон
`accent` 10 %, обводка `accent` 35 %. Тап → список прокси. Состояния:

| Состояние | Цвет | Текст |
|---|---|---|
| подключено через XRAY | `accent` | `XRAY · nl-1 · 85 мс` |
| подключается / переподключение | `warn` | `XRAY · nl-1 · подключение…` |
| нет связи с сервером | `error` | `XRAY · nl-1 · нет связи` |
| напрямую (пользователь выбрал) | `warn` | `Напрямую, без XRAY` |
| обычный прокси (SOCKS5/MTProto) | `warn` | `Прокси без XRAY` (без адреса) — см. FEAT-20 |

## Заставка и вступление

- **Заставка при запуске** (Android splash, iOS LaunchScreen, macOS — n/a): фон `bg`, по центру иконка
  (`branding/xraygram-icon-1024.png`) 176 pt, скругление 40, мягкое свечение `accent` 25 %.
- **Вступление** (первый экран): иконка, по ней сверху вниз проходит луч (полоса `accent` 55 % с размытыми краями +
  тонкая линия `accent-hi`), 1,2 с, один раз; ниже `XRAYGRAM` моноширинным 28, разрядка 6; подпись
  «Неофициальный клиент Telegram, который подключается через ваш сервер XRAY.» (текст — по FEAT-06/19) (`text-2`); кнопка «Начать» (`accent`);
  «Русский · English». Анимация — кодом (картинка + движущийся градиент), Lottie не нужен.

## Экран «Подключение через XRAY»

Надзаголовок `XRAY · VLESS` (моноширинный, `accent`, разрядка 2), заголовок «Подключение через XRAY», поле ссылки
моноширинным на `surface` с обводкой `accent`, под ним превью ссылки: «✓» и цвет `accent`, текст по FEAT-01 («Сервер: vless · host:port · имя»), кнопка «Подключить»,
«Сохранённые серверы» (пинг: `accent` < 150 мс, `warn` выше), внизу неприметное «Подключиться без XRAY (напрямую)».
