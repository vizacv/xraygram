# Брендинг Xraygram

Иконка — **рентген обезьянки** (Xray = рентген): весёлая обезьянка в гарнитуре, видна светящаяся кость,
в поднятой руке — бумажный самолётик в виде каркаса. Исходник — `source/xraygram-xray-chatgpt.webp`
(сгенерирован владельцем в ChatGPT, 2026-11-18). Первая версия (обезьянка с белым самолётиком) — `source/xraygram-mockup.jpg`
и в git-истории; больше не используется.

Все файлы ниже генерируются скриптом, руками не правим:

```bash
upstream/venv-tools/bin/python -I tools/branding/make_icons.py
```

Что поправлено относительно исходника: чёрные скруглённые углы залиты фоном (скругляет сама ОС); для круглых масок
Android картинка уменьшена и окружена размытым продолжением фона, чтобы кончик самолётика и рука не обрезались.

Знак Telegram и знак Xraygram **не ставим** на то, что уходит другим людям (видеокружки, QR) — FEAT-19 §3.

**Когда встраивать:** со следующими изменениями каждой платформы, отдельной пересборки ради иконки не делаем
(решение владельца 2026-11-18). Это FEAT-07. Кто уже встроил первую версию — заменить на эту при следующей правке.

**Сходство с логотипом Telegram** теперь небольшое: нет синего круга и сплошного белого самолётика,
самолётик — прозрачный каркас. Для публичной раздачи стоит ещё раз глянуть, но риск низкий.
