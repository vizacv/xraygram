# Брендинг Xraygram

Иконка — обезьянка с гарнитурой и бумажным самолётиком на сине-голубом фоне. Исходник — макет владельца
`source/xraygram-mockup.jpg` (2026-11-18). Все файлы ниже генерируются скриптом, руками не правим:

```bash
upstream/venv-tools/bin/python -I tools/branding/make_icons.py
```

Что поправлено относительно макета: убраны белые поля и надписи «XRAYGRAM / TELEGRAM FORK + XRAY CORE»
(в иконке текст нечитаем), фон сделан сплошным квадратом без скругления (скругляет сама ОС),
самолётик возвращён внутрь квадрата (раньше вылезал за рамку и обрезался бы маской).

| Файл | Для чего |
|---|---|
| `xraygram-icon-1024.png` | мастер, квадрат 1024 без прозрачности |
| `xraygram-character.png` | персонаж на прозрачном фоне (для экранов, сплэша, README) |
| `ios/AppIcon-1024.png` | iOS: AppIcon (Xcode сам нарежет размеры) |
| `macos/Xraygram.icns`, `macos/xraygram-macos-1024.png` | macOS: скруглённый квадрат по сетке Apple с тенью |
| `android/ic_launcher_background.png` + `ic_launcher_foreground.png` | Android: адаптивная иконка (432 px, персонаж в безопасной зоне 66%) |
| `android/mipmap-*/ic_launcher{,_round}.png` | Android: старые иконки 48–192 px |
| `android/play-store-512.png` | 512 px, если понадобится |
| `preview.png` | как выглядит в масках: iOS, macOS, круг Android |

**Когда встраивать:** со следующими изменениями каждой платформы, отдельной пересборки ради иконки не делаем
(решение владельца 2026-11-18). Это FEAT-07.

**Риск:** правила Telegram для форков просят не использовать их логотип (белый самолётик в синем круге).
У нас главный элемент — обезьянка, самолётик у неё в руке, но синий круг и белый самолётик похожи на их лого.
Для теста с друзьями нормально; перед публичной раздачей стоит сделать самолётик/круг менее «телеграмовскими».
