# Xraygram macOS — ручные проверки

Около 40 минут. Для звонков нужен второй человек с Telegram на телефоне. ID проверок — из [plan.md](plan.md).
Результаты пишите прямо сюда, в квадратные скобки: `[ok]`, `[нет: что случилось]`.

## 0. Подготовка (1 мин)

Запустите Xraygram как обычно (двойной клик), XRAY-запись выбрана и «подключено».
В Терминале, из папки проекта, запустите наблюдение за сетью и не закрывайте его до конца проверок:

```bash
cd ~/xraygram && testing/scripts/net-watch.sh
```

Скрипт печатает только подозрительное: `УТЕЧКА` (Телега ходит наружу мимо xray), `UDP` (открыт UDP-сокет, это звонки),
`CORE?` (core ходит не на VPS), `WEBVIEW` (встроенный браузер ходит наружу). Если таких строк нет, всё идёт через xray.
Адрес VPS он прячет как `<VPS>`. Если что-то появилось, отметьте, что вы делали в тот момент.

## 2. Звонки (10 мин, со вторым человеком)

Галки «Использовать прокси для звонков» в этой версии нет: в tdesktop 7.4.4 её убрали из настроек. По коду звонки
идут **напрямую**, мимо xray (подробности — в отчёте, MAC-01/02). Задача — подтвердить это и понять, работают ли звонки
у вас вообще.

1. [ ] Во втором окне Терминала запомните счётчик трафика core:
   ```bash
   nettop -P -L 1 -p $(pgrep xraygram-core | head -1) | tail -1
   ```
2. [ ] CALL-02: позвоните второму человеку (голос), говорите 1 минуту.
   - Соединилось? Сколько секунд висело «Соединение»? ____
   - Слышно в обе стороны? Качество? ____
3. [ ] CALL-03: пока идёт звонок, смотрите в окно `net-watch.sh`:
   - строки `UDP Telegram[...]` значат, что звонок идёт **напрямую**: xray у нас принимает только TCP, так что любой
     UDP-сокет Телеги идёт мимо него. `УТЕЧКА ... TCP →` во время звонка — тоже прямой путь (TCP до сервера-ретранслятора);
   - если таких строк нет, а счётчик core из шага 1 вырос примерно на 0,5–1 МБ за минуту, звонок идёт **через xray**.
   Повторите команду из шага 1 после звонка. Байты выросли? ____
   Куда именно идёт UDP (во время звонка, в третьем окне):
   ```bash
   nettop -m udp -n -L 1 -p $(pgrep -f 'Xraygram.app/Contents/MacOS/Telegram$')
   ```
   Адреса `91.108.*` или `149.154.*` — серверы Telegram, другие — прямое соединение с собеседником (P2P).
4. [ ] CALL-04: то же с видео.
5. [ ] CALL-05: групповой звонок (видеочат в группе): зайдите, поговорите. Смотрите на те же строки.
6. [ ] CALL-06 (по желанию): Настройки → Продвинутые → Тип соединения → отключите прокси, позвоните ещё раз,
   потом включите XRAY обратно. Сравните: стало хуже или лучше?

Если звонок не соединяется, это ожидаемо для прямого пути из РФ. Запишите, на каком шаге застряло.

4. [ ] ENT-06: у XRAY-записи нет «Поделиться»/QR (ключ не должен утечь).
5. [ ] ENT-04: удалите вторую (неактивную) запись, закройте окно прокси. Выполните `pgrep -lf xraygram-core`:
   сколько процессов? ____ (по коду ожидаю, что лишний core живёт до перезапуска, MAC-06)
