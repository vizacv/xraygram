# FEAT-20 — Тема «Рентген» и значок статуса XRAY (этап 2)

Приоритет: **P1**. Решение владельца 2026-11-19: направление «А · Рентген». Токены, заставка, вступление —
`branding/theme-rentgen.md`, макет — `branding/mockups/rentgen.dc.html`. Делать после FEAT-19.
Задачи на выравнивание — PAR-22…PAR-24 в `product/parity.md`.

## Зачем

Xraygram должен с первого взгляда отличаться от Telegram. Друг должен всегда видеть, идёт ли он через свой сервер,
без захода в настройки прокси. Тема меняет только цвета, раскладка экранов остаётся upstream (полного редизайна
нет). Значок статуса — одна строка над списком чатов.

## Поведение (одинаково на всех платформах)

### Тема

1. Встроенная тема **«Рентген»** стоит в списке тем рядом со стандартными темами Telegram. Стандартные не трогаем.
2. **По умолчанию:**
   - на чистой установке — «Рентген»;
   - при обновлении поверх старой сборки — «Рентген», если пользователь сам тему не выбирал (стоит тема upstream по
     умолчанию); выбранную тему не трогаем;
   - выбор пользователя сохраняется, «Рентген» его не перебивает.
3. «Рентген» — тёмная тема, от светлой/тёмной темы системы не зависит. Автопереключение на ночную тему upstream по
   умолчанию выключено. Если пользователь включит его сам — как в upstream.
4. Фон чата — сплошной `bg` без узора. Обои пользователь может сменить, как обычно.
5. **Палитра** — токены из `branding/theme-rentgen.md`. Соответствие ролям интерфейса:

| Роль | Токен |
|---|---|
| фон экранов, список чатов, фон чата | `bg` `#0B1220` |
| шапки, панель ввода, поля, карточки, меню | `surface` `#121B2E` |
| входящий пузырь | `surface-2` `#18233A` |
| исходящий пузырь / его время | `bubble-out` `#10403A` с обводкой `rgba(62,242,200,.3)` / `#7FD9C2` |
| разделители и обводки | `separator` `#16213A`, `border` `#1C2840`/`#22304A` |
| основной текст / вторичный (время, превью) / подсказки | `text` `#E6F1FF` / `text-2` `#8EA3BF` / `text-3` `#5F7391` |
| кнопки, ссылки, бейджи непрочитанного, «в сети», галочки прочтения, переключатели, плавающая кнопка | `accent` `#3EF2C8`, нажатие `accent-hi` `#8FFBE0`, текст на акценте `on-accent` `#04211B` |
| предупреждения (переподключение, «напрямую», «Без XRAY») | `warn` `#F2B33E` |
| ошибки (нет связи, ошибка ссылки, удаление) | `error` `#FF6B6B` |
| заглушки аватаров | `#F28CB1 #7FB2FF #3EF2C8 #B49CFF #F2B33E #8EE07A`, текст `#0B1220` |

   Ключей тем у платформ сотни. Платформа сопоставляет их ролям сама и записывает таблицу у себя
   (`<платформа>/decisions.md`). Если ключ не подходит ни к одной роли — ближайший по смыслу; сомнения — продукту.
6. Свечение `accent` (тень 24 px, 35 %) у плавающей кнопки и значка статуса — по желанию платформы, если дёшево.
7. **Моноширинный шрифт** — только для технических данных: значок статуса, имя сервера и пинг, поле ссылки
   `vless://`, надпись `XRAYGRAM`. Системный моноширинный (SF Mono / Roboto Mono / Menlo). Встраивание JetBrains Mono
   не обязательно (P3).

### Значок статуса XRAY

8. Пилюля по центру под заголовком списка чатов (на вкладках папок — тоже). Скрыта, пока открыт поиск. Состав:
   точка + текст, моноширинный 12, фон — цвет состояния 10 %, обводка — 35 %, точка и текст — цвет состояния.
9. **Тап** → список прокси (тот же экран, что Настройки → … → Прокси).
10. **Состояния** (приоритет сверху вниз — показывается первое подходящее):

| Состояние | Когда | Цвет | RU | EN |
|---|---|---|---|---|
| нет сети | у устройства нет сети (upstream «Ожидание сети») | `text-2` | Нет сети | No network |
| напрямую | прокси выключен, пользователь выбрал «напрямую» | `warn` | Напрямую, без XRAY | Direct, without XRAY |
| другой прокси | активна не-XRAY запись (SOCKS5 / MTProto) | `warn` | Прокси без XRAY | Proxy without XRAY |
| нет связи | ядро активной XRAY-записи не работает (`XRAY: <причина>`, FEAT-02) **или** подключение длится > 20 с при живой сети | `error` | XRAY · <имя> · нет связи | XRAY · <name> · no connection |
| подключение | Telegram в состоянии «Подключение…» / «Обновление…» через XRAY-запись | `warn` | XRAY · <имя> · подключение… | XRAY · <name> · connecting… |
| подключено | Telegram подключён через XRAY-запись | `accent` | XRAY · <имя> · <N> мс | XRAY · <name> · <N> ms |

   - `<имя>` — имя записи из `#fragment` (FEAT-02), длиннее 16 символов — обрезать с «…».
   - `<N>` — последний пинг активной записи тем же механизмом, что в списке прокси. Обновлять не чаще раза в 60 с, пока
     список чатов на экране. Пинга ещё нет — без последней части: `XRAY · <имя>`.
   - Пока действует блокировка FEAT-03, список чатов не виден, значок не нужен.
11. Заголовок списка чатов upstream («Xraygram», «Подключение…», «Обновление…») ведёт себя как раньше. Значок —
    дополнительная строка, не замена.
12. Доступность: у пилюли метка для экранного диктора — тот же текст + «Открыть настройки прокси».

### Экран «Подключение через XRAY» и окно XRAY в теме

13. Тексты и поведение — FEAT-01/03 без изменений. Оформление:
    - надзаголовок `XRAY · VLESS` моноширинным, `accent`, разрядка 2;
    - поле ссылки моноширинным на `surface`, обводка `accent` (при ошибке — `error`);
    - строка превью: успех — `accent` с «✓» в начале, ошибка — `error`;
    - кнопка «Подключить» — `accent`;
    - «Подключиться без XRAY (напрямую)» — `text-3`, без акцента.
14. «Сохранённые серверы»: если платформа уже пингует записи — пинг справа (`accent` < 150 мс, `warn` ≥ 150 мс,
    `error` недоступен). Если не пингует — без пинга (отдельной работы не требуем).

## Платформенные отличия (допустимые)

- Механизм темы свой: Android — встроенная `.attheme`/`Theme.ThemeInfo`, iOS — `PresentationTheme`
  (built-in), macOS — встроенная палитра `.tdesktop-theme`.
- Место значка: Android и iOS — под заголовком списка чатов; macOS — над списком чатов под полем поиска левой
  колонки (заголовка там нет). При узкой колонке на macOS — только точка с подсказкой при наведении.
- Свечение — по возможности.
