# FEAT-01 — Тип прокси «XRAY (VLESS)»

Приоритет: **P1**. Статус по платформам — `docs/backlog.md`. Расхождения — `product/parity.md`.
Связано: BUG-08 (сырые английские ошибки), FEAT-02 (список), FEAT-03 (экран XRAY использует то же поле и превью).

## Зачем

Обычный человек получает от владельца одну строку `vless://…` (в WhatsApp, VK, SMS — Telegram у него заблокирован).
Ему нужно вставить её в одно поле и нажать одну кнопку. Ни адреса, ни порта, ни логина, ни выбора протокола.
Отдельный тип в штатном окне прокси — там, где пользователь Telegram и так ищет «прокси» (меню «⋮» владелец отверг).

## Поведение (одинаково на всех платформах)

1. Пользователь открывает штатный список прокси Telegram и нажимает «Добавить прокси».
2. Открывается штатное окно прокси. Тип **XRAY (VLESS)** стоит **первым** в списке типов и **выбран по умолчанию**.
   Остальные типы (SOCKS5, HTTP, MTProto) остаются как в Telegram.
3. При выбранном XRAY вместо адреса/порта/логина видно одно многострочное поле «Ссылка» и подсказка под ним.
4. Если в буфере обмена уже лежит ссылка (`vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`), она
   подставляется в поле сама при открытии окна. Ничего другого из буфера не подставляем.
5. Через ~300 мс после последнего изменения поля ссылка проверяется тем же разборщиком, что запускает xray
   (libXray). Пока проверка идёт — «Проверяю ссылку…». Результат — одна строка под полем:
   - успех: `Сервер: <протокол> · <хост>:<порт> · <имя>` (имя — `#fragment`, URL-декодированное; если его нет —
     без последней части);
   - ошибка: `Ошибка: <понятный текст>` (таблица ниже). Сырой текст ядра показываем только в конце, в скобках, если
     ошибка не из таблицы.
   Если платформа умеет разобрать ссылку мгновенно (Android), строку «Сервер: …» можно показать сразу, а проверка
   ядром лишь подтверждает или заменяет её на ошибку.
6. Кнопка сохранения (штатная: «Сохранить» / «Готово» / галочка):
   - при пустой или ошибочной ссылке запись **не создаётся**, поле подсвечивается ошибкой;
   - при верной — создаётся запись, она **становится активной, прокси включается** («сохранить и подключиться»).
7. Ссылка хранится только локально, в защищённом хранилище приложения (не в аргументах процессов, не в логах).
8. Повторное открытие записи (редактирование) — то же окно, выбран XRAY, в поле текущая ссылка. Сохранение
   заменяет ссылку в той же записи (без дубля) — подробнее FEAT-02.

### Понятные ошибки (BUG-08)

Сопоставление делается по ответу проверки ядра. Текст ядра — в логах, пользователю — эта таблица.

| Условие | RU | EN |
|---|---|---|
| поле пустое | Вставьте ссылку на сервер | Paste the server link |
| начинается с `http://` или `https://` | Это ссылка на сайт или подписку. Нужна ссылка на один сервер: vless://, vmess://, trojan://, ss:// или hysteria2:// | This is a web or subscription link. A single-server link is needed: vless://, vmess://, trojan://, ss:// or hysteria2:// |
| `unsupported share format` (не та схема) | Это не ссылка на сервер. Нужна ссылка vless://, vmess://, trojan://, ss:// или hysteria2:// | This is not a server link. Use vless://, vmess://, trojan://, ss:// or hysteria2:// |
| `no valid outbound found` (не хватает полей, битый UUID/порт, нет `pbk` у Reality) | В ссылке не хватает данных (адрес, порт, ключ или параметры). Скопируйте её целиком ещё раз | The link is incomplete (address, port, key or parameters). Copy the whole link again |
| таймаут / ядро не ответило | Не удалось проверить ссылку. Попробуйте ещё раз | Could not check the link. Try again |
| прочее | Ссылка не распознана (<текст ядра>) | Link not recognized (<core text>) |

## Платформенные отличия (допустимые)

- **iOS:** система не даёт прочитать буфер без действия пользователя → вместо автоподстановки (шаг 4) кнопка
  «Вставить ссылку из буфера» над полем; поле принимает обычную вставку; Return убирает клавиатуру.
- **Android:** быстрый разбор ссылки в Java даёт строку «Сервер: …» сразу, проверка ядром — следом.
- **Хранение** разное (macOS — `tdata/xraygram.json` 0600; Android — `SharedConfig`, ссылка в поле `secret`;
  iOS — Postbox, `.xray(link:)`). Для пользователя одинаково.
- **Кнопка сохранения** — штатная для платформы.

А — QA автоматически, Р — руками (владелец/QA), К — по коду. В скобках — ID из `testing/plan.md`.

| F01-02 | Скопировать рабочую `vless://` с `#имя`, открыть «Добавить прокси» (macOS/Android) | ссылка уже в поле; через ≤ 1 с строка `Сервер: vless · host:порт · имя` | Р (CON-01) |
