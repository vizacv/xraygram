# FEAT-09 — Уведомления без Firebase (Android)

Приоритет: **P1** (поднят продуктом с P2, предложение владельцу — см. `product/roadmap.md`, В4).
Платформы: **Android**. macOS — n/a (приложение на рабочем столе само держит соединение). iOS — n/a: с бесплатным
Apple ID push невозможен; ограничение пишем в инструкции (FEAT-17), а не лечим.

## Зачем

Пуши Firebase в форке не работают (ключи привязаны к официальному пакету). Сейчас, чтобы приходили уведомления,
нужно найти в настройках два выключателя и ещё разрешить работу в фоне в настройках Android. Друг этого не сделает и
решит, что «Xraygram не работает». Это главный риск теста на телефонах друзей.

## Поведение

1. В сборке Xraygram **по умолчанию включены** «Keep-Alive Service» и «Background Connection» (раздел «Уведомления и
   звуки»). Пользователь может их выключить — тогда как upstream.
2. После первого успешного подключения через XRAY (FEAT-03, «Подключить») и только если приложение ещё ограничено
   системой по батарее — один раз показываем объяснение (тексты ниже) с кнопкой «Разрешить», которая открывает
   системный запрос «Не оптимизировать расход батареи» для Xraygram (`ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`).
   «Не сейчас» — закрыть; повторно не спрашиваем, но в «Уведомления и звуки» есть строка «Работа в фоне» с тем же
   действием и текущим состоянием.
3. Если Android 13+ и разрешение на уведомления ещё не дано — запросить его в том же шаге (штатный системный запрос).
4. Постоянное уведомление фоновой службы (Android требует его для foreground service) — с текстом из таблицы, без
   слова «Telegram» и без адреса сервера.
5. xray живёт в процессе приложения: пока жив процесс, жив и прокси — ничего отдельного не запускаем.

## Тексты UI

| Ключ | RU | EN |
|---|---|---|
| объяснение, заголовок | Уведомления в фоне | Background notifications |
| объяснение, текст | Xraygram получает сообщения через ваш сервер XRAY, без сервисов Google. Чтобы уведомления приходили, когда приложение закрыто, разрешите ему работать в фоне. | Xraygram receives messages through your XRAY server, without Google services. To get notifications while the app is closed, allow it to run in the background. |
| кнопки | Разрешить · Не сейчас | Allow · Not now |
| строка в настройках | Работа в фоне: разрешена / ограничена | Background activity: allowed / restricted |
| постоянное уведомление | Xraygram на связи | Xraygram is connected |

## Платформенные отличия

Только Android. На некоторых прошивках (Xiaomi/MIUI, Huawei, Samsung) есть свои «автозапуск»/«спящие приложения» —
их не автоматизируем, а описываем в инструкции для друга (FEAT-17).

## Критерии приёмки

| ID | Проверка | Ожидается | Кто |
|---|---|---|---|
| F09-01 | Чистая установка → экран XRAY → «Подключить» | после подключения объяснение «Уведомления в фоне»; «Разрешить» открывает системный запрос | Р (эмулятор — А через adb) |
| F09-02 | `dumpsys deviceidle whitelist` после «Разрешить» | `io.github.xraygram` в списке | А |
| F09-03 | Настройки → Уведомления и звуки на чистой установке | Keep-Alive и Background Connection включены | А/Р |
| F09-04 | Приложение смахнуто из недавних, экран выключен 15 мин, прислать сообщение | уведомление приходит ≤ 1 мин | Р (телефон) |
| F09-05 | Сеть в фоне | соединения процесса только на 127.0.0.1 и от xray к VPS; без Firebase/Google | А (adb + `/proc/net/tcp`) |
| F09-06 | «Не сейчас» и перезапуск приложения | объяснение больше не появляется; строка «Работа в фоне: ограничена» в настройках | Р |
