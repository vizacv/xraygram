# FEAT-03 — Экран «Подключение через XRAY»

Приоритет: **P1**. Решение владельца 2026-11-18 (`docs/decisions.md`). Исходные правила — `macos/decisions.md`,
раздел «Экран XRAY»; эта спека — канон для всех платформ. Связано: BUG-04, BUG-05, FEAT-01 (поле и превью),
FEAT-02 (удаление последней записи, выключение прокси).

## Зачем

Обычный клиент Telegram при первом запуске сразу идёт к серверам Telegram напрямую — провайдер (ТСПУ) это видит ещё
до того, как пользователь добавил XRAY. Друг, поставивший Xraygram, должен сразу увидеть один экран: «вставь ссылку».
И ни байта в сторону Telegram, пока он этого не сделал или явно не согласился «напрямую».

## Поведение (одинаково на всех платформах)

### Состояние

1. **Заблокировано** = в списке прокси нет ни одной XRAY-записи **и** пользователь не выбирал явно «напрямую»
   (флаг `directAllowed`). Первый запуск (настроек нет) = заблокировано.
2. Флаг `directAllowed` **сбрасывается** при добавлении любой XRAY-ссылки. Значит, удаление последней XRAY-записи
   снова приводит к экрану.
3. Если пользователь уже вошёл и XRAY-записи есть — ничего не меняется, экран не показывается.

### Пока заблокировано

4. Никаких соединений с Telegram: MTProto всех аккаунтов (и экран входа) получает «чёрную дыру» — SOCKS5
   `127.0.0.1:1`. Поиск запасных адресов (DoH к Google/Cloudflare/Mozilla, Firebase, прямые IP с **снятым** прокси)
   не запускается. Прочий HTTP клиента — туда же. Сохранённые настройки прокси не меняются: блокировка сверху.

### Экран

5. Модальный, поверх всего (и экрана входа, и чатов). Не закрывается Esc / кликом мимо / свайпом / «Назад».
   Если его закрыла смена экрана — показывается снова. Когда блокировка снята любым путём (например, XRAY-запись
   добавлена через `vless://`-ссылку или через окно прокси) — экран закрывается сам.
6. Содержимое сверху вниз:
   - заголовок; поясняющий текст (два варианта: нет сохранённых / есть сохранённые);
   - **Сохранённые серверы** (только если есть): по строке `XRAY · <имя>` на каждую ранее добавленную ссылку + строка
     «Новая ссылка». Выбор одной строки (радиокнопки).
   - поле ссылки с подсказкой и превью — **как в FEAT-01** (тот же формат «Сервер: …», те же понятные ошибки).
     Если сохранённые есть, поле видно только при выбранной «Новая ссылка»;
   - кнопка **«Подключить»** (основная);
   - внизу неприметная ссылка **«Подключиться без XRAY (напрямую)»**.
7. **Выбор по умолчанию:** если в буфере ссылка — «Новая ссылка» с подставленной ссылкой; иначе первый сохранённый
   сервер; если сохранённых нет — поле ссылки.
8. **«Подключить»:**
   - новая ссылка: проверить (как FEAT-01), при ошибке — ошибка под полем, экран остаётся; при успехе — добавить
     XRAY-запись, выбрать её, включить прокси;
   - сохранённый сервер: запустить его ядро, вернуть запись в список прокси, выбрать, включить прокси; при ошибке —
     короткое уведомление «Ошибка: …»;
   - после успеха блокировка снимается, сессии переподключаются через XRAY, экран закрывается.
9. **«Подключиться без XRAY (напрямую)»** → подтверждение «Подключиться напрямую?» (тексты ниже, красная кнопка).
   Подтвердил → `directAllowed = true`, применяются обычные настройки прокси (напрямую или ранее выбранный не-XRAY
   прокси), экран закрывается. Отмена — остаёмся на экране.

### Когда появляется

10. При старте, если заблокировано (первый запуск; старый профиль без XRAY).
11. Сразу после удаления последней XRAY-записи (подтверждение — FEAT-02, п. 9).
12. **Сохранённые серверы:** ссылки удалённых XRAY-записей не выбрасываются, а хранятся как неактивные (ядро для них не
    запускается), максимум **20**, новые сверху, дубли по ссылке схлопываются. Кнопки «забыть ссылку» в этой версии нет.

### Доступ к прокси до входа

13. На экране ввода номера телефона всегда есть кнопка/значок «Прокси» (штатно в Telegram она появляется только после
    таймаута подключения) — чтобы добавить второй сервер или сменить ссылку до входа.

## Платформенные отличия (допустимые)

- **iOS:** буфер без действия пользователя не читается → п. 7 «если в буфере ссылка» не работает; по умолчанию —
  первый сохранённый сервер; над полем кнопка «Вставить ссылку из буфера». Заголовок раздела — заглавными по стилю
  iOS (`СОХРАНЁННЫЕ СЕРВЕРЫ`). Экран — оверлей в верхнем навигаторе после появления экрана входа/чатов.
- **Android:** «Назад» сворачивает приложение (экран не закрывается). Хранение — `mainconfig`
  (`xraygram_direct_allowed`, `xraygram_saved_links`).
- **macOS:** модальное окно поверх главного; хранение — `tdata/xraygram.json`.
- Путь «Вернуться к XRAY» — разный (см. выше).

| F03-01 | Чистая установка, первый запуск, наблюдение за сетью 2 мин | экран поверх всего; у процесса клиента **ни одного** соединения наружу, кроме 127.0.0.1:1 (отказ); DNS-запросов к именам Telegram/DoH нет | А (CON-05, LEAK-08) |
