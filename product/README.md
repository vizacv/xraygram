# Xraygram — продукт

Ведёт тема «Продукт» (product owner): бэклог, спецификации, единое поведение на всех платформах, тексты UI.
Регламент — `docs/process.md`. Бэклог — `docs/backlog.md`.

- [features/](features/) — спецификации `FEAT-NN.md`: зачем, поведение по шагам (одинаково для macOS/Android/iOS),
  тексты RU/EN, допустимые платформенные отличия, критерии приёмки `FNN-NN` для QA.
  Сейчас: FEAT-01, 02, 03, 04, 09 (P1), FEAT-15 (P2, этап 1 в текущей пачке).
- [parity.md](parity.md) — матрица «как сделано на каждой платформе» и задачи на выравнивание `PAR-NN`.
- [roadmap.md](roadmap.md) — порядок работ, новые идеи, вопросы владельцу `ВN`.

Правила для спек: «XRAY» в текстах для пользователя — заглавными; язык строк — по языку системы (RU, иначе EN);
отличие платформы допускается, только если оно записано в разделе «Платформенные отличия» спеки.
